# Admin Super Panel Report

This report documents the platform controls available to site administrators.

---

## 1. Governance & Management
- **User Governance**: Enables search, filtering, suspension, activation, and removal of user accounts.
- **Verification Management**: Interface to inspect and approve seller PAN, GST, and bank routing details.
- **Audit Logging**: Captures administrative changes and exports logs for compliance audits.

---

## 2. Content & Support
- **Content Management (CMS)**: Interface to manage promo banners, pages, and blog resources.
- **Support Desk**: Connects agents to live customer chat sessions over WebSockets.
