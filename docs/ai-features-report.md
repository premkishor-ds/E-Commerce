# AI Features Report

This report documents the machine learning and analytical intelligence features.

---

## 1. Recommendations & Search Ranking
- **AI Recommendations**: Serves related products using collaborative filtering models based on user purchase histories.
- **Search Ranking**: Enhances MongoDB text search using relevance weights (ratings, sales velocity, view counts).

---

## 2. Platform Safety & Forecasting
- **Fraud Detection**: Flags suspicious transactions (e.g. rapid consecutive checkout attempts from different locations).
- **Inventory Forecasting**: Predicts restock dates based on historical sales velocity.
- **Sentiment Moderation**: Uses NLP models to flag fraudulent or abusive reviews.
