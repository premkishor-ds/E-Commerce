# 22 — Admin Actions

## Goal
`ADMIN_ACTIONS` → maps to intents: `ADMIN_PRODUCTS`, `ADMIN_ORDERS`, `ADMIN_USERS`, `ADMIN_COUPONS`, `ADMIN_ANALYTICS`

## Description
Admin users manage products, orders, users, coupons, and view analytics/audit logs.

## Permission Required
`Admin` or `Super Admin` role only.

## Action Mapping
| Intent | Action |
|--------|--------|
| `ADMIN_PRODUCTS` | CRUD products, bulk import/export, approve products |
| `ADMIN_ORDERS` | View all orders, update status, approve refunds |
| `ADMIN_USERS` | List users, manage roles |
| `ADMIN_COUPONS` | Create/manage coupons |
| `ADMIN_ANALYTICS` | View sales stats, audit logs, reports |
