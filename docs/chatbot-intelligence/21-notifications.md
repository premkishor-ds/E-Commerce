# 21 — Notifications

## Goal
`NOTIFICATIONS` → maps to intent: `NOTIFICATION_PREF` and `PRICE_ALERT`

## Description
User wants to manage notification preferences, enable/disable alerts, or set price drop / restock alerts.

## Action Mapping
| Intent | Action |
|--------|--------|
| `NOTIFICATION_PREF` | `NotificationService.getPreferences()` / `updatePreferences()` |
| `PRICE_ALERT` | Save alert on user profile |
