# 01 — Capability Discovery

## Goal
`CAPABILITY_DISCOVERY` → maps to intent: `HELP`

## Description
User wants to know what the chatbot can do, what features exist, how to use it, or wants a menu of options. This is the most common first-turn intent for new users.

## Action Mapping
`HELP` → Show feature overview with suggestions

## Expected Entities
None required. Optional: `role` (Customer / Vendor / Admin)

## Clarification Rules
No clarification needed — always respond with capability overview.
