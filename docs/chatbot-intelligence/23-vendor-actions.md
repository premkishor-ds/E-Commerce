# 23 — Vendor Actions

## Goal
`VENDOR_ACTIONS` → maps to intents: `VENDOR_PRODUCTS`, `VENDOR_ANALYTICS`, `VENDOR_SETTLEMENTS`

## Description
Vendor/Seller users manage their product listings, view sales analytics, and check payout settlements.

## Permission Required
`Vendor`, `Seller`, `Admin`, or `Super Admin` role.

## Action Mapping
| Intent | Action |
|--------|--------|
| `VENDOR_PRODUCTS` | CRUD own products, update price/stock/variants |
| `VENDOR_ANALYTICS` | View own sales stats and revenue |
| `VENDOR_SETTLEMENTS` | View payouts, commissions, pending settlement |
