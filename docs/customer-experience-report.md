# Customer Experience Report

This report outlines the customer retention and experience systems.

---

## 1. Engagement Modules
- **Wishlist & Comparisons**: Persisted in local storage and synced with user records on sign-in.
- **Product Subscriptions**: Enables auto-delivery cycles (e.g. monthly) with recurring payment options.

---

## 2. Loyalty & Referral Programs
- **Reward Points**: System rewards customers with loyalty points for successful transactions.
- **Referrals**: Tracks new user registrations using referral codes, awarding bonuses to both parties on checkout completion.
